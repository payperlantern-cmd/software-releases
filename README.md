# Software releases

Public release packages and update metadata only. No application source code or development history is published here.

## VideoDrop

[Download VideoDrop 1.5.0](https://github.com/payperlantern-cmd/software-releases/releases/tag/videodrop-v1.5.0). Windows 10/11, .NET Framework 4.8.

- Downloads and update checks require no GitHub account or token.
- VideoDrop 1.5.0 already uses this repository by default. Keep the token field empty.
- Users upgrading from 1.4.x must install 1.5.0 manually once, preserving tools and settings.
- Startup update checks have a 24-hour cooldown; manual checks are available. Installation asks for confirmation.
- If you configured a token during the previous private-release setup, select the option to remove that saved token in App update source.

The repository became public on 2026-11-10. Earlier packaged documentation may describe private access; that setup is no longer needed for this repository.

Update manifest: `updates/videodrop.json`. Download the versioned VideoDrop ZIP from Releases; GitHub automatic source archives contain only release-repository documentation/metadata.
